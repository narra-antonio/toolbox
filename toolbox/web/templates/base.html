Quick Start

Run toolbox config init <root> to scan and register your Git repositories.

Commands

  • config init <root> — Scan a folder and register all Git repos
  • config add <path> — Add a new repo or folder
  • switch --default — Switch all repos to their default branch
  • switch <projects> --branch <branch> — Switch selected repos to a branch
  • pull --all — Pull all repos
  • pull <project> — Pull a specific repo
